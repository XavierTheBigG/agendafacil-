AGENDAFÁCIL
========================================

Projeto desenvolvido para demonstrar
padronização de interfaces utilizando
diferentes linguagens de programação.

TELAS
========================================

1 - Clientes
Linguagem: Python
Tecnologia: Flask

2 - Agenda
Linguagem: Java
Tecnologia: Java Swing

3 - Serviços
Linguagem: PHP


PADRÃO VISUAL
========================================

Cor principal:
Azul

Ação principal:
Adicionar

Ação de edição:
Editar

Ação de exclusão:
Excluir

Os títulos possuem o mesmo padrão.

Os campos possuem o mesmo estilo.

Os botões possuem cores padronizadas.

As três telas possuem a mesma identidade
visual.


COMO EXECUTAR PYTHON
========================================

Abra o terminal do VS Code.

Entre na pasta:

cd python

Instale o Flask:

pip install -r requirements.txt

Execute:

python app.py

Abra no navegador:

http://127.0.0.1:5000


COMO EXECUTAR JAVA
========================================

Entre na pasta:

cd java

Compile:

javac Agenda.java

Execute:

java Agenda


COMO EXECUTAR PHP
========================================

Entre na pasta:

cd php

Execute:

php -S localhost:8000

Abra no navegador:

http://localhost:8000/servicos.php
